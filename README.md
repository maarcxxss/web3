# Web3

Repositorio personal de aprendizaje y desarrollo sobre **Blockchain, Ethereum, Solidity y Web3**.

El objetivo de este repositorio es reunir diferentes proyectos prácticos y experimentos reproducibles para estudiar el desarrollo de Smart Contracts y aplicaciones descentralizadas.

---

## 📂 Estructura

### `standards/`

Implementaciones y experimentos relacionados con estándares de Ethereum.

Actualmente:

- [`erc20/`](./standards/erc20/) — implementación y pruebas de un token ERC-20 desde cero.

### `defi/`

Proyectos relacionados con conceptos de **DeFi**.

Actualmente:

- [`staking/`](./defi/staking/) — proyecto de staking de tokens.

### `security/`

Experimentos relacionados con seguridad de Smart Contracts.

Actualmente:

- [`reentrancy/`](./security/reentrancy/) — estudio y demostración de ataques de reentrancy.
  - `staking/` — implementación práctica del escenario vulnerable y su protección.

## 🧪 Filosofía

Los proyectos se desarrollan intentando comprender **qué ocurre realmente en cada paso**, evitando limitarse a copiar implementaciones.

Cada proyecto busca ser:

- reproducible;
- probado;
- documentado;
- independiente;
- útil como referencia para futuros proyectos.
